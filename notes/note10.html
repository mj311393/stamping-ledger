编制：冯国庆 H0362　　日期：2026-11-16　　适用：舒勒高速自动线（南京江宁 · 上汽大乘用车）· 4PR 侧围 / 前盖内板 拉延与修边工序

素材口径：现场记录取自本周台账（11月9日—11月12日 四个白班，共 13 个产品记录、57 条问题，数据源 /workspace/peach/work/ledger_data.json）；行业判据取自文末来源清单原文，凡有数字的都写数字。

一、背景认知：这两类问题在线的哪个位置

产线是舒勒国内第一条高速自动线，节拍快、单件价值高。这意味着两件事：缺陷发现晚一件，报废就是几十件；模具上多扛一次异常，修模就是半天。

本周两个主题都落在「模具面」：

  • 一个是拉延成形面：C柱窗框这类型面急变区，贴合不良 → 局部进料受阻 → 减薄率升高 → 先出暗伤、再变开裂。
  • 一个是修边排废：废料没落下、没切断 → 上行被压料板压住 → 压料板损坏、模体 R 角开裂。

责任分界按现行口径：模具类（暗伤、开裂、压印、拉毛）的具体措施由模具供应商与工程部主导，我方盯两件事——批次复现与耗时变化；现场能立刻做的是「不让它恶化」的那几步，写在第四节。

二、本周现场（台账原话）

2.1 C柱窗框：从暗伤到开裂

11月9日白班，4PR左侧围（814 件，8:00-10:33）原话：

生产至480件时，线尾右侧检验员发现C柱窗框上方开裂，现场往前追溯开裂报废38件，发现时生产第三包用料50张（料架号B033）；现场供应商调整平衡块增加垫片后消除，第四包换料后C柱暗伤又加重，供应商继续调试维持生产；上批次首末检件正常，本批次产品已安排全部挑选。累计耗时：32分钟。

同班 4PR右侧围（546 件，11:20-13:46）原话：

op10暗伤（C柱窗框），供应商在线调试，效果不好拆模让道，累计耗时：15分钟。

11月10日同产品复核（并入同一条跟踪）：

本批次生产C柱窗框位置暗伤正常。

从这三段原话里能读出三件事：

  1. 发现得太晚：生产到 480 件才被线尾检验员看到，往前追溯报废 38 件。高速线上从「首件」漂到「被发现」，中间夹着几百件。
  2. 两个因子同时存在：调平衡块加垫片后开裂消除——说明压料面/支撑高度不匀造成局部过度减薄；换第四包料后暗伤又加重——说明来料这一侧也有份（同模具、换包料即变化）。
  3. 首末件正常不等于安全：上批次首末件正常，本批到 480 件才裂。同一周还有一条同类风险——11月11日 4PR后门内板「末检右后门门框少一孔，首检正常，翻库检查初步结果第32件开始少孔」，也是首件正常、过程中偏出。

2.2 卡废料 → 压料板顶坏、模体 R 角开裂

11月11日白班，4PR前盖内板（1150 件，13:14-15:50）原话：

op20压料板因卡废料导致压料板损坏模体开裂，拆模让道累计耗时26分钟。

同批同工位另一条：op20卡废，累计1次耗时7分钟。

同一周其它卡废（同一工位、不同产品）：11月10日 4PR右侧围 op20 卡废 1 次 3 分钟；11月11日 4PR后门内板 op20 卡废 4 次 12 分钟；11月12日 4PR右侧围 op20 卡废 1 次 3 分钟。

链条是这样的：废料没落下/没切断 → 上行时被压在压料板与下模之间 → 压料板承压超限 → 压料板损坏，力往下传到模体，R 角这种应力集中处先开裂。单次卡废只有 3～12 分钟，但一次顶坏就是拆模让道 26 分钟，再加修模与停线，成本放大一个量级。

三、行业依据与判据

3.1 拉延开裂，先按 8 条对号

长城汽车技术中心那篇文章把拉延开裂拆成 8 条，每条都给了「现场怎么看出来」，正好可以当排查顺序用（原文摘要见 raw/draw_crack_debug.txt）：

判据现场怎么看出来与我们本周的对应
压料力太大，板料被压死开裂件板料轮廓与成形后几乎一致、没有走料痕平衡块加垫片＝在改压料/支撑高度
凹模口或拉深筋槽圆角太小裂在制件立面；凹模入口圆角一般取 R凹=(6～10)×tC柱窗框上方正是型面急变区
压料面粗糙度差、研合率低裂在工艺补充面与压料面接触处研合率低同时会带来拉毛
毛坯放偏、定位不稳裂的对侧起皱、拉延筋外料面积不稳与拆垛上料位置歪同源
料片尺寸太大压料面积大、压料力作用足换包料时先核料片规格
料片质量不符（厚度公差、表面、材料级别）同一副模具换包料即变化11月9日第四包换料后暗伤加重
凸凹模间隙过小 / 闭合高度过小局部间隙过小或整体闭合高度低加垫片就是在改间隙分布
局部形状变形条件恶劣上面几条都调不动只能加工艺切口/工艺孔

两个有用的量：

  • 开裂与褶皱通常占拉深废品总数的 80%～90%（长城汽车，AI《汽车制造业》2016-09-30）。也就是说，拉延这一关守住这两样，废品大头就守住了。
  • 减薄率：η=(t0−t)/t0×100%。覆盖件工程上把 20%～25% 当警戒；TWB 前门内板那个案例，企业标准是最大减薄率不超过 25%、最大失效小于 0.8 就认为不会开裂（《制造技术与机床》2022 年第 8 期）。超过这个量级，暗伤就是开裂的前一站。

3.2 暗伤看的是「减薄与贴合」，不是看颜色

暗伤按我们的术语口径＝目视不明显、侧光才看得出的轻微凹陷，多为型面局部贴合不良。它和开裂是同一条链上的两个阶段：贴合不良 → 局部进料受阻 → 减薄升高 → 先暗、后裂。所以判暗伤不能只看「有没有坑」，要看三样：

  1. 位置：是不是集中在型面急变区（C柱窗框、A/B 柱根部、轮罩、棱线）。
  2. 边界：裂口是发生在减薄明显的立面/圆角（拉裂），还是从切边处起裂（剪切边缘问题）——这两种修法完全不同，前者调压料/间隙/圆角，后者查修边刃口与刃入量。
  3. 批次性：同一位置连续两批出现，就不是偶发；换包料就变化，就把来料一起纳入。

现场可做的检测手段按投入排序：侧光/斜射光目视（零成本，最实用）→ 首末件与换料首件加检 → 网格/散斑或蓝光扫描取应变（重大项目、要与供应商对账时用）→ 已裂件断面观察确认是颈缩拉裂还是剪切起裂。

3.3 废料不下滑，是模具损坏的第一诱因

长城汽车 2012 年那篇修边模文章讲得很直白：修边模废料处理非常重要，往往会因为废料无法排出和排出困难导致模具损坏、生产效率低，并存在较高的安全隐患。四条结构原因、四种卸料手段，都能对着现场查：

  • 结构原因：① 废料刀设计不合理（同一废料上不得出现两个拐角、废料刀之间不可干涉、刀间方向要平行或张开）；② 滑料板坡度小（滑道 ≥25°、滚道 ≥15°）；③ 废料刀背空小；④ 与模具其它部件干涉（例如安装螺丝是否正落在滑料方向上）。
  • 卸料手段：卡料部位加弹顶销/弹顶器；装活动挂臂，滑块打开时把废料挑出；用弹簧或气缸把废料顶出；滑料板上装振动器。
  • 另一条常被忽略的因果：废料切不断的第一原因是「没有及时清理、废料堆积」，最后在上修边刀块的压力下把废料刀崩刃（模具机械工程师）。修废料刀还必须兼顾刀块高度——修高了与上修边刀块干涉、再坏一次；修低了继续切不断。

关键数字（同两篇原文）：

  • 钢板冲压模单边刀口间隙取料厚 1/20；用板料试冲验间隙，毛刺高度不大于料厚 1/10 即合格；修边毛刺另有验收原则：长度不超过料厚 1/3，且不影响本工序、下工序与使用安全。
  • 压料芯压料力取冲裁力的 5%～20%（薄料取低值、复杂件取高值；间隙小于料厚 10% 时退料力会明显增大）；压料芯距修边线理论 0.5mm，现场直边 0.5～1mm、拐角约 2mm。
  • 料渣硌伤四条成因：修边刃口间隙过紧挤料、刃口刃入量过深带料、刃口长期磨损产生磁性粘料、板料自身韧性差。对策＝调间隙＋减刃入量＋刀块消磁＋料吹净装置（用机床高压空气在线清洗）。

3.4 压料板被顶过，不能只看「复位了没有」

压料板变形/凹陷的行业修法是焊补后与下型面研配（红丹找点、检查压料面是否局部凹陷）。这条对我们现场的意义是：卡废顶一下，即使当时看着没事，也可能留下局部凹陷或微裂，后序表现为压印、带料，甚至在同一个地方长出一个新的开裂点。所以卡废后的动作不是「复位继续干」，而是「清干净＋看压料面＋看模体 R 角」。

四、可执行排查/对策清单

A. 暗伤 → 开裂（每次上线照做）

  1. 首件、换包料后首件、每包料首件，侧光目视 C柱窗框、A/B 柱根部、轮罩这类型面急变区；只报「正常/异常」，异常必须拍位置照并记件号。
  2. 发现异常立刻记「从第几件开始」，与料架号绑定（本周是 B033 第三包、用料 50 张），追溯范围按「上一次检验合格点 → 发现点」全部挑选，不要只挑当包。
  3. 换包料视为工况变化，首件必须重检，上一包的「正常」结论不顺延（11月9日第四包换料后暗伤加重就是这条的反证）。
  4. 模具侧交供应商与工程部：平衡块垫片、压料面研合率、凹模与拉深筋圆角、凸凹模间隙与闭合高度。我方只记「调整了什么、什么时候调、调整后首件结果」，用耗时与批次复现判断成效，不替他们写方案。
  5. 开裂与暗伤件单独标识、单独存放，不与合格件混放；报废数、件号区间当日进台账。
  6. 同一位置连续两批出现按「两批次沉默」规则判闭环，不许因为一批正常就销账（本次 11月10日复核正常只是第一批正常）。

B. 卡废 → 保护模具（卡废后的固定动作）

  1. 卡废停机后，先把压料板与下模之间的废料、碎渣清干净再合模。带料合模等于拿模具当锤子。
  2. 每次卡废后三步点检：压料面有无新印痕/凹陷 → 废料刀高度与间隙 → 模体 R 角与筋板有无裂纹（手电＋侧光，必要时着色渗透）。
  3. 废料刀与滑道按周点检：单边间隙≈料厚 1/20、刃口刃入量按标准、滑道 ≥25°/滚道 ≥15°、背空与紧固件不挡料道。
  4. 排废不畅的部位加弹顶销、挂臂或振动器；毛刺偏大的刀块先消磁再做料吹净。
  5. 卡废按「产品＋工位」记次数与单次分钟。频次上升说明模具状态在恶化，提前安排检修，不要等到顶坏压料板再拆模。
  6. 4PR前盖内板 op20（P43，已单独立项）：供应商介入结论、拆模修配内容、复产后首件与连续 200 件的压料面检查，三项都要落到台账；在此之前该条按「持续跟踪」挂着，不销账。

五、专业技能小课堂

5.1 Excel：做一张「暗伤/开裂批次追踪表」

这类问题最怕「每批各写各的」，写完看不出复现。八列就够：日期｜班次｜产品｜工位｜现象｜发现件号或区间｜报废件数｜耗时（分）。

几个能直接抄的公式（按上面列序，假设数据从第 2 行开始）：

  • 同一产品同一现象历史出现几次：=COUNTIFS($C:$C,$C2,$E:$E,$E2)
  • 本周是否复现：=COUNTIFS($A:$A,">="&DATE(2026,11,9),$A:$A,"<="&DATE(2026,11,15),$C:$C,$C2,$E:$E,$E2)
  • 连续批次数（先按产品＋工位排序，再加一列辅助）：=IF(AND(C3=C2,E3=E2),N(F2)+1,1)
  • 该产品累计报废件数：=SUMIFS($G:$G,$C:$C,$C2)
  • 该产品平均单批耗时：=AVERAGEIFS($H:$H,$C:$C,$C2)

三处设置让它「自己会报警」：① 现象列做数据验证下拉（暗伤/开裂/压印/拉毛/卡废/垃圾/擦模），同一个问题只许一种叫法；② 条件格式：出现次数 ≥3 填红、=2 填琥珀，耗时 >20 分标红；③ 数据透视表，行＝工位、列＝现象、值＝计数与耗时求和——一眼看出哪个工位在反复咬人。

口径提醒（跟台账一致）：跨批次只比单批值和折算分/百件，不做耗时累加；没有件数的批次不折算、不参与横比。

5.2 CAD/成形分析：FLD 与减薄率怎么读

  • 减薄率：η=(t0−t)/t0×100%，t 取成形后最小厚度（实测或仿真厚度云图）。增厚率同理，(t−t0)/t0。
  • 成形极限图（FLD/FLC）五个区：拉裂区、安全区、起皱趋势区、起皱区、严重起皱区。应变点落在 FLC 曲线下方＝不裂；落在单向拉伸直线左侧＝起皱区。工程上「厚度变化」和「成形极限」一起看：前者判断危不危险，后者指出哪里危险。
  • 凹模入口圆角经验值 R凹=(6～10)×t；覆盖件要求进料阻力均匀，材料易流动处加拉延筋，筋高与布置直接改各部位的材料流动分配。
  • 压边力是双刃剑：小了起皱、大了拉裂。仿真优化的公开案例里，把压边力 800kN 降到 600kN、摩擦系数 0.12 降到 0.08、拉深筋深度降到 6mm 后，减薄率、起皱区与开裂区都明显改善（汽车纵梁案例）。现场加垫片、调平衡块，本质就是在改这套「阻力分配」。
  • 所以判读顺序是：先看缺陷位置（立面/圆角/压料面/切边）→ 再怀疑该处进料阻力（压料面、筋、圆角、间隙）→ 最后才谈材料。反过来先怪材料，往往查不出所以然。
