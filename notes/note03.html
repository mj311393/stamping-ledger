产线背景：舒勒 Schuler 国内第一条高速自动线 · 南京江宁 · 现属上汽大乘用车
本期周期：2026-09-28 ～ 2026-10-11 现场记录（近 14 天）
本期选题依据：台账「未闭环遗留」58 条中，「感应器/信号闪断」在 9/28、10/5、10/6、10/10、10/11 五个批次反复出现，横跨后门内板 / 后门外板 / 右侧围 / 前门内板多个产品；「拉毛 / 油光」在 10/10 右侧围单批次内反复 4 次。两条都是「重复出现、可落成排查清单」的问题，不是随机故障。

一、背景认知：为什么盯这两个

高速自动线上，「料片到位」的信号就是整条线的安全开关与节拍开关：信号一「闪断」，轻则停线、重则模具在无料状态动作，直接吃开动率。更要紧的是，闪断类问题最容易被当成「感应器坏了」一换了之——但从台账看，同样的闪断在同一工序、同一个线速门槛上反复出现，说明它更像「可诊断的系统问题」，不是单纯的器件失效。

拉毛 / 油光这条线的特点是会反复：擦完模短时间内又出来，处理次数和停机时长都很难压下去。它和铁屑、刃口间隙、模具工作表面三件事锁在一起，属于「找到源头才能少擦模」的典型。

两条线的共同点：把「偶发」变成「可诊断、可留痕、可验证」。

三、行业依据与判据

3.1 闪断不只是「感应器坏了」——四类扰因逐条对现场

黑金刚《影响双张检测器性能的有哪些因素？》（板料检测器的扰因分类，与我们的料片到位检测同源）把扰因归成四类，逐条能对上现场：

  • 材料 / 位置特性：材料厚度、材质（冷轧钢 / 不锈钢 / 铝的导电率、磁导率不同）会影响信号的穿透与反射；表面油污、锈迹、涂层、凹凸会干扰信号接收——厚油污会削弱信号强度，表面凸起可能"模拟"出错误的厚度特征而引发误报警。→ 对应现场「料片窜动 / 板料油污」。
  • 环境干扰：电焊机、高频电机、变频器会产生电磁辐射，传感器离得太近（建议 3 m 以上安全距离）会导致信号紊乱、检测延迟或误动作；工业级传感器适宜 -10℃～60℃、湿度 90% 以下（无冷凝）。→ 高速线附近伺服 / 变频器密集，是闪断的可疑外部源。
  • 设备运行与维护：端拾器 / 传送带等结构剧烈振动，会让传感器与被检材料的相对位置频繁变化、超出稳定检测距离，影响检测一致性；发射 / 接收端积灰、金属碎屑会遮挡信号路径、降低灵敏度；元件长期老化会衰减，需定期校准或更换。→ 这是「感应器松动 / 脏污 / 老化」的行业依据。
  • 参数与校准：未按材料厚度设定「灵敏度阈值」会误判；未开启「抗抖动（防抖 / 滤波）」时，高速送料中材料轻微弹跳可能被直接判为异常；长期不校准，会因环境变化或元件老化而漂移。→ 直接把「12 次/分才闪断」解释成"响应窗口 / 防抖没跟上线速"。

3.2 一个可迁移的「误报」判据

澳星电子《防盗报警系统的误报及原因分析》虽是安防行业，机理可直接搬：误报主要来自①设备故障（含漂移性故障——温度等让元器件参数漂移，表现为"时好时坏"）②设计 / 施工不当（选型、安装位置、固定不牢、灵敏度没调好）③环境噪扰④使用不当；而降低误报的成熟做法是「双鉴」——两种不同原理的探测器同时确认到目标才报警。

迁移到我们这条线：

  • 闪断先分清是「器件坏」还是「位置 / 环境扰动」；单点信号不足以定性。
  • 条件允许时用双信号互证（前门内板 op40 本来就「两感应器」，正好做互证）+ 短延时防抖，把「真报警」和「扰报」分开统计。
  • 换件前先做完位置 / 清洁 / 参数的记录，换件后同工况复测，避免"换了但没解决"。

3.3 拉毛 / 油光发白的判据

拉深 / 冲压件表面拉痕的六大成因（深圳金威《五金冲压件缺陷产生原因及其预防措施大全》十七）：

  • A 凸模或凹模表面有尖利的压伤 → 修磨或抛光压伤表面。
  • B 凸凹模间隙过小或间隙不均匀 → 拉深时工件表面被刮伤，调整间隙至合适。
  • C 凹模圆角表面粗糙 → 将圆角修磨打光。
  • D 冲模工作表面或材料表面不清洁、混进杂物从而压伤工件表面 → 保持凸凹模表面清洁，坯料拉深前一定擦拭。
  • E 凸凹模硬度低时，表面附有金属废屑也会产生拉痕 → 提高硬度，并时常检查、及时清除表面废屑。
  • F 润滑剂质量差会加大表面粗糙度 → 用适合拉深工艺的润滑剂，必要时过滤后使用，防止杂质混入损伤工件表面。

现场「OP20 拉毛、油光发白」正落在 B（间隙）+ D/E（异物、废屑）+ F（润滑）+ 工作表面粗糙度 这几条的组合上。

铁屑是这条线的"发动机"（中国钢桶包装网《铁屑问题的应对措施》，手工线模具改自动线后的攻关记录）：

  • 冲压产生的铁屑极易粘附在模具和零件表面，进而在制件表面压出凹痕；线尾质量检测人员识别出压痕缺陷时，至少已造成 7 个以上的返工或报废。
  • 该厂把手工线模具改自动线的重点就是解决修边掉铁屑，节拍从 3～5 spm 提到 6～10 spm 后，模具必须做必要改造才能适应封闭自动线。
  • 他们的整改数值（可作我们操刀时的对照基准）：直修刀块基准面"波浪"部位修顺、刀面正锥改为 90° 垂直面、刃口啃伤修复锋利、基准面控制在 10mm；冲头吃入量由 10mm 改到 5mm 内、上部刃口修整平整、刃口和周圈推光抛光；刃口与压料板之间的间隙由原来的 0～0.1mm 调整为 0.5～0.7mm（用红丹研配使间隙均匀）；废料刀与刀块间隙由 7mm 调至 1mm，吃入量由 12mm 调至 4mm。

现场可用的一条判据：擦模后同批次内很快又出现拉毛 / 油光 → 优先怀疑「铁屑源没清干净」或「间隙偏大在持续产屑」，而不是"打磨次数不够"。也就是说，先断屑源、再抛表面，顺序反了就会一直擦。

四、可执行排查 / 对策清单

A. 闪断（顺序：先物理 → 再参数 → 最后换件）

  1. 固定与位置：逐序查感应器 / 支架的紧固情况、有无松动移位；用同规格标准板在同一位置反复放料 20 次，看信号是否每次都给——偶发不给先查"检测窗口太小"。
  2. 清洁与遮挡：擦拭感应头，清掉积灰 / 铁屑 / 油污；检查线缆有没有被废料砸、被端拾器蹭的痕迹（10/9 叶子板 op30 跳电，排查结果就是「模具感应器线被 op20 带过来的废料压坏」）。
  3. 相对运动：核对限位与托料器——前门内板已点出「限位卡太死、料片可窜动、托料器舌头太短行程过长容错太低」，先把定位 / 支撑做稳，让料片在检测窗口里"待得住"。
  4. 参数与防抖：把感应器 / PLC 侧的防抖延时、滤波与当前线速匹配；「12 次/分才闪断」就按线速重新标定响应窗口，记录改前 / 改后数据。
  5. 互证与留痕：op40 有两个感应器，试点「双信号互证 + 短延时」，把误报和真报分开统计（与"双鉴"判据一致）。
  6. 换件要有依据：换感应器前先做完 1～5 的记录，换后同工况复测。

B. 拉毛 / 油光

  1. 断屑源：检查 OP20 修边 / 冲孔刃口间隙是否偏大、刃口是否钝化（间隙不当 + 刃口变钝是毛刺与掉屑的主因）；刃口与压料板、废料刀间隙按标准值回收（对照 3.3 的 0.5～0.7mm / 1mm 基准）。
  2. 清屑与吹扫：在 OP20 前后强化铁屑清除（吹扫 + 吸屑），模具型腔、废料道每班清一次。
  3. 表面与润滑：OP20 工作表面的拉毛点、硬点打磨到位并抛到规定粗糙度；核对润滑剂型号与涂覆量是否与板料 / 工序匹配，必要时过滤润滑剂。
  4. 记录闭环：把「拉毛出现次数 / 时长 / 擦模位置」记成表（本周 10/10 就是 4 次、约 41 分钟），下周对比看趋势。

五、专业技能小课堂

本周挑两个能立刻用的：质量工具（5Why + 鱼骨图） 和 Excel 三招。

5.1 5Why + 鱼骨图——就拿本周的「闪断」实操一遍

5Why（一条链问到"缺什么制度"才停）：

  • Why1 为什么停线？——op10 感应器信号闪断，模具在没料状态动作。
  • Why2 为什么闪断？——高速时料片位置微动 / 弹跳，检测窗口失稳。
  • Why3 为什么线速一到 12 次/分才出现？——防抖延时 / 响应窗口没跟着线速标定。
  • Why4 为什么没跟？——换批次、提速时，没有"检测参数随线速同步复核"的作业要求。
  • Why5 为什么没有要求？——缺一条"提速 / 换批次前必须复核检测参数"的检查项。

鱼骨图（中间画一条脊，指向"OP10 闪断"；四条大骨）：

  • 人：换批次 / 提速时未复核参数，凭经验直接开线。
  • 机：感应器松动或老化、托料器行程过长、限位卡太死。
  • 料：板料平整度、表面油污影响检测信号。
  • 法：缺"提速前复核检测参数"的检查表，缺少闪断次数 / 时长的记录。
  • 环：线体振动、附近变频器 / 伺服带来的电磁干扰。

落到一条能执行的标准：线速改动（例如提到 12 次/分）前，必须先复核 op10 / op40 的检测参数并留记录。

5.2 Excel 三招（本周直接能做）

  • 数据透视：把「闪断 / 拉毛」按 日期 × 班次 × 工序 拉一张「停线次数 × 时长」表，一眼看出哪个工序最咬节拍。
  • 条件格式：给「停线时长 > 15 分钟」或「同批次拉毛 ≥ 2 次」的格子上色，超差自动跳出来。
  • XLOOKUP / VLOOKUP：用「产品名 + 工序」当键，把本周记录与上次同款批次比对，判断是"老问题复发"还是"新问题"。
