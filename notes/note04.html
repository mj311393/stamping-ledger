一、背景认知：为什么这两件事最该盯

  1. 我们线的设计节拍是「高速」——舒勒高速自动线连续模式的目标节拍远高于普通机器人线（行业里机器人线七轴化后才 12~15 件/min）。也就是说，线尾的产出速度是按 13~15 次/min 配的，可线尾装箱还是靠人。这是全厂节拍链上最脆的一环。
  2. 台账口径：截至 2026-10-18，共 16 批次 / 52 条产品记录 / 124 条问题，未闭环 78 条；近 14 天新增 76 条。把这些条目按「类型」聚一下，「装箱/节拍」是出现最频、牵扯产品最多的一类（前盖外板、前门内板、尾门内外板、左侧围、叶子板、后门外板都中招），而且它直接表现成「全线降速」——是能算出钱的那类损失。
  3. 第二个方向是 4PR后门内板 op30 那条链：夹紧器 → 装模高度 → 氮气缸，从 10/6 到 10/12 走完了一个完整闭环。它是「模具/装模高度管理」的现成样本，值得把口径固化下来，以后照做。

二、本周现场（引台账原话）

2.1 线尾装箱跟不上 → 全线降速（按时间倒序）

  • [10月18日 白班] 4PR前盖外板｜类型:装箱/节拍｜问题:线尾装箱容易出错，多次停机。 对策:现场维持10次生产，继续跟踪线尾装箱
  • [10月11日 白班] 4PR左侧围｜问题:线速10次生产正常，第11次时线尾装箱跟不上，无人处理存在安全隐患，目前维持降速生产状态。对策:维持降速生产（线速10次）；线尾装箱需专人处理
  • [10月11日 白班] 4PR前门内板｜问题:线速由12次降至9.5次，线尾装箱跟不上；原因是产品大，料架难装、容易出错（10次开始装箱就开始赶）。
  • [10月11日 白班] 4PR尾门内外板｜问题:线速12次线尾装箱来不及（逐步降至8次）；小件只有一个人无法同时顾两边，北侧小件离得远不方便拿，现场做了一个钩子辅助拿取。 线尾装箱来不及主要在于外板，原因大概率是人员技能太差，下批次生产再试验（已单人测试装箱情况，料架不难装）。（今天观察平伟供应商装箱能力明显低于其他家供应商，并且总是换人）
  • [10月11日 白班] 4PR前盖外板｜问题:线速13次降至10次生产，主要问题线尾装箱跟不上，产品容易变形以及不好拿取。如果装箱这边可以改个朝向，或许能够提升一些。
  • [10月10日 白班] SHB叶子板｜问题:始生产装箱跟不上，线速由13次降至10次后生产正常。｜另有:线尾产品输送间距看着有些大，下批次关注调整。
  • [10月10日 白班] SHB后门外板｜问题:线尾装箱跟不上线速，线速由12降至10次，生产至250件后恢复线速12生产。
  • [10月9日 白班] 4PR后门外板｜问题:初始线速13次时线尾装箱来不及（供应商换人，跟不上节拍）。 对策:冲次降至11生产，至450件恢复13次；现场培训供应商装箱手法；安排线尾检验人员关注，来不及装箱及时停机确保人员作业安全

三、行业依据与判据

3.1 线尾装箱为什么会成为全线瓶颈（有据可查）

  • 机器人冲压自动化线的典型构成＝机器人／电控／拆垛／过渡皮带／清洗机／涂油机／对中台／线尾码垛系统／安全防护／端拾器。行业原文：「自动化冲压线的生产节拍能够超过 10 件/min，这时线尾码垛工位的负荷就超过劳动极限，为了适应这种高节奏的产出，需要先对冲压件成品进行分流，然后由人工或机器人将其码入料架，最后由铲车将料架运走。」（来源：搜狐《机器人冲压自动化生产线》，已存 raw/line_end_pack_sohu2.txt）

→ 对应我们：节拍一旦上 13 次，单靠一个人装箱就已经超过劳动极限，现场「12→8」「13→10」的降速，本质是「人的极限」在替「系统的产能」买单。

  • 行业里机械手高速线/七轴机器人线的连续节拍做到 12~15SPM（奥图 Aotto 资料：七轴机械手 15SPM 连续模式；碳纤维七轴系统「节拍稳定达到13SPM，实现从拆垛、传送至码垛的全流程自动化」；并配 ATC 3 分钟自动更换端拾器）。

→ 对应我们：「从拆垛到码垛全流程自动化」是行业已经做到的事；我们线尾还停在人工装箱，这就是差距所在，也是提速的天花板。

  • 可量化判据（现场用）：单人工位的稳定承接节拍 ≤10~11 次/min；线速目标 ≥13 次时，线尾必须满足「分流（南北两落料点）或双人 或 辅助工装」三条里至少一条，否则不许提速。

3.2 不是「人慢」，是系统没标准化（SMED 视角）

  • SMED 项目原文（300T 案例）：「换模时间长并不只是操作人员动作慢，而是吊装、工装、物料、人员、设备接口、参数、品质确认和信息传递未按同一节奏协同。」 做法＝把可提前完成的作业外部化、必须停机完成的作业并行化+标准化，并建立首件放行机制；该项目换模时间由约 14 小时缩短至 7 小时。（来源：qilylean 案例，raw/smed_300t_case.txt）

→ 我们 10/9「等备件」就是典型的内部作业外部化没做：备件没在停机前齐套，停机时间被白等吃掉。

  • 换模的经典三步（新乡重夫／丰田，4 小时→3 分钟）：① 区分内部作业（必停机做）与外部作业（可停机前做）；② 把内部作业尽量转成外部；③ 消除调整（用块规、限位、标准化模高，做出「不需要调整的换模」）。（来源：网易 SMED 文章，raw/smed_case_163.txt）

→ 「消除调整」落到我们身上就是把装模高度写成数字基准：4PR后门内板 op30 标准 1335、临时 1280，必须有一张「标准装模高度表＋变更记录」，而不是每次靠师傅经验调。

  • 一个直观对照：行业把「模具高度标准化、夹紧与定位标准化」当成缩短换模的前提；我们这次的 35mm 下调正说明装模高度是有标准值的量，可以也应该被管理。

3.3 夹紧器 / 氮气缸：同一组函数，按顺序量

  • 快速换模的液压/机械夹紧与自动定位：每套模 4~8 个夹紧器，夹紧力约 50~200kN；配蓄能器保压（断电后仍能维持夹紧）；零点定位系统重复定位精度可达 ±0.01mm，换模可压到 3~5 分钟。（来源：青岛嘉赫祥《冲压模具快速换模系统中的液压夹紧与自动定位技术》，raw/smed_hydraulic_clamp.txt）
  • 氮气弹簧（氮缸）维护判据（来源：zgdnkco《模具氮气弹簧使用维护》，raw/ng_spring_check.txt）：
  • 班前点检；班中巡检每 2~4 小时一次：看温度（正常工作温度 ≤60℃，烫手立即停机）、看出力（工件起皱／压料不均／顶出无力＝大概率漏气泄压）、看密封处（缸口、充气阀无结霜、无油渍）。
  • 下线／收模：模具完全打开让氮缸完全复位，不要长期处于压缩状态，避免密封件疲劳老化。
  • 每 1~2 万模次复测出力、检查充气压力，轻微泄压统一补氮；每 5 万模次／半年拆解检查密封件、导向套，老化磨损直接更换；满设计寿命（常规 1~3 万次）强制整体检修或报废，不带病使用。
  • 禁忌：严禁超额定行程、严禁侧向力／偏心安装、严禁高温明火、严禁私自拆解焊接钻孔改造。
  • 判据（这次的直接用法）：「夹紧器失效」和「装模高度」「氮气缸压力」「上模异物」是同一组函数。西北角有缝隙 → 夹紧器无法工作，先按 ① 上模异物 → ② 装模高度实测 → ③ 氮气缸压力 三条顺序量；10/6 靠「下调装模高度 35mm」暂时压住，说明量到的是「高度/压力」这一层，10/9 又复发就说明根子在夹紧器本体或氮气缸压力衰减，10/12 换氮气缸＋装模高度回 1335 是对的处置方向。

四、可执行排查 / 对策清单

A. 线尾装箱（按影响从大到小）

  1. 定标准：写清「单人工位节拍上限 10~11 次/min」；线速目标 ≥13 次时，装箱位必须满足「分流／双人／辅助工装」之一。
  2. 分流：件大件（前盖外板、门内板、尾门内外板）与件小件分落料点、分人；「小件只有一个人无法同时顾两边」（10/11 尾门内外板）就是没分流。
  3. 朝向与间距：按件固定装箱朝向——4PR前盖外板「改个朝向或许能提升」可以直接试验（成本最低的一条）；线尾输送间距按件设定（SHB叶子板 10/10 已提）。
  4. 辅助工装：北侧远件推广现场那根钩子（10/11 尾门内外板自制）——零成本、马上能用，做成标准件。
  5. 料架容错：料架难装 → 改内衬／加限位；提速前先给装箱留容错（9/22 左侧围「连续提速后装箱没有容错」＝教训）。
  6. 人员：装箱岗定人不轻易换；供应商（如平伟）装箱手法现场培训＋考核，换人必须交接（10/9、10/11 两次都是「换人跟不上」）。
  7. 安全底线：来不及装箱就停机（10/9 已做），绝不许「无人处理赶件」（10/11 左侧围明确写了「无人处理存在安全隐患」）。

B. 换模 / 装模高度 / 氮气缸·夹紧器

  1. 建「标准装模高度表」：每套模每个工序一个数字（如 4PR后门内板 op30 = 1335）；任何临时值（1280）必须注明原因＋恢复条件＋责任人。
  2. 换模前齐套清单：吊具、工具、紧固件、易损备件（夹紧器、氮气缸）在停机前到位——别停机才等备件（SMED 外部化）。
  3. 换模后三步验证：装模高度实测＝标准值 → 夹紧器逐个试动作（含西北角等死角） → 氮气缸压力复测。
  4. 氮气缸台账：到货／更换／装模高度 一起记（10/12 已做），并按 1~2 万模次复测出力、5 万模次／半年拆检密封件。
  5. 首件放行：换模后首件必须过检才算换模结束（SMED 的首件确认机制），杜绝「换了模先跑起来再说」。
  6. 突发换模的定位偏移（9/28 SHB前地板 Y 轴跑偏 25mm、缺参考样本）→ 换模后测一次对中／定位，缺基准就先把「正常值」存下来，下次才有比对。

五、专业技能小课堂

5.1 PPT：质量周会「一页一问题」模板（本周就能用）

目标：周会上只讲本周最贵的那 1~2 个问题（比如「线尾装箱导致全线降速」），其余进附录，别开成念表会。

单页结构（四段，一眼看完）：

  1. 现状：一张现场照片 ＋ 一行量化（例：4PR前门内板 线速 12→9.5 次）。
  2. 根因：鱼骨图/一行结论（例：产品大、料架难装→单人工位超劳动极限）。
  3. 对策：排水法列 2~3 条，带责任人和时限。
  4. 效果：一张对比（改善前/后 节拍或停机分钟）。

PowerPoint 里怎么做：

  • 柏拉图（找主攻）：Excel 先做「问题类型-次数」排序 + 累计占比，然后 插入→图表→组合图（柱形＝次数、折线＝累计%，次坐标轴）；做完把图选择性粘贴成图片进 PPT，避免链接断。
  • 甘特图：插入→图表→堆积条形图；第一段（开始日期）填充设为无色，第二段（持续天数）着色，纵轴反向排序。
  • 母版：把「现状-根因-对策-效果」做成 4 个占位文本框的版式，以后一键套用。

5.2 CAD：看图必认的三个符号 ＋ 展开料／间隙回弹速算

必认符号（图纸左上/右下角那排框）：

  • 形位公差框：平面度（外板件最常用）、平行度、垂直度、同轴度、位置度（孔位）；读法＝「公差项目｜公差值｜基准」，如「平行度 0.1 A」表示相对基准 A 的平行度不超 0.1mm。
  • 表面粗糙度：Ra 数值（如 Ra1.6/Ra3.2），带▽三角；外板件看外表面 Ra 与波纹度，内板看拉毛敏感处。
  • 基准符号：A/B/C 方块＋箭头，是测量与加工的落脚点，改模前先认基准在哪。

展开料（粗算，现场用）：

  • 直角折弯多段：L ≈ Σ直线段 + Σ (π/2)·(R + K·t)，K≈0.3~0.45（软钢取 0.4 左右）；R 是内圆角半径，t 是料厚。
  • 只求快时：L ≈ Σ直线段 + 0.4t×折弯次数（近似）。
  • 提醒：K 值随 R/t 变，精确值查材料表；定位孔／工艺切口要在展开图上一起带出来。

间隙：

  • 冲裁（落料/冲孔）双面间隙 ≈ (5%~10%)·t（软钢偏大端，硬料偏小端）。
  • 拉深单边间隙 ≈ (1.0~1.1)·t（末次拉深可取 1.0t）。

回弹：外板件回弹靠拉延筋／压边力／过拉深控制；改模前先量回弹角再定补偿量，别凭手感敲模。

DXF 核算：容器里能读 DXF（ezdxf 库），可以帮你算轮廓周长、孔位坐标、展开长、间隙是否达标——有图纸丢给我，我跑给你。
